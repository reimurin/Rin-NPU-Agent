# Rin NPU Agent 1.6.0-alpha.3

## 本版变化

LoRA 管理已接入原应用的生图流程。可以扫描 SDXL `.safetensors` 文件、编辑 `<lora:名称:0.8>` 权重标签，并将提示词带回生图页。加载器按实际 WAI 层名和矩阵尺寸检查兼容性，多 LoRA 按秩拼接组合；未覆盖的结构会报出原因，不会静默漏掉权重。

配套模型采用七段 WAI UNet，原生分辨率为 1024×1024，适配 SM8750 / DSP V79，每层组合总秩上限为 64。模型组件独立下载，约 7.14 GiB；原有 CLIP、VAE 和普通生图模型保留。组件标签为 `wai-lora-sm8750-r64-partitioned-v1`，不要混用 16 段 rank32 组件。

预设的置顶、编辑、删除及 LoRA 页面使用 Rin 公共控件。本轮视觉检查还修正了预设名称栏浮动标签与正文重叠的问题，并增加单行、多行输入框在获得和失去焦点时的间距检查。

## 安装与使用

直接覆盖安装本 APK，不要卸载原应用。包名仍为 `com.geniex.demo`，版本号为 1.6.0-alpha.3，versionCode 为 20，沿用原签名。

在生图设置中打开 LoRA 管理，安装配套组件，把兼容文件放到 `Download/sdxl_qnn/Lora/`，刷新列表后插入标签并应用到生图页。权重设为 0 或移除标签可回到原底模路径。首次使用前按安装器提示预留组件及临时合并空间。

## 验证范围

74 项 Android 单元、交互和离屏原生界面检查通过。既有分段加载器的 24 项 CPU 数值回归通过；参考 SDXL LoRA 的 722 组权重已完成文件、层映射与投影数值检查。

完整 WAI 配合真实 LoRA 在手机上的出图效果、耗时和内存占用尚待实测。这是 alpha 预发布，不替换正式版 Latest。
