# Rin NPU Agent 1.6.0-alpha.2

本版恢复原位升级，修复 LoRA 页面首次显示崩溃，并加入预设管理。它仍是预发布版本；正式 Latest 保持 1.5.11。

## 安装与入口

直接覆盖原来的 Rin NPU Agent，无需卸载、清数据或重新下载模型。applicationId 为 `com.geniex.demo`，versionCode 19，继续使用历史证书和原 MainActivity 启动入口。之前独立安装的“Rin LoRA 1.6 测试”不是本次更新对象，可以忽略；不要卸载原来的生图 APP。

进入生图模式后，打开左侧设置，选择“LoRA 管理与 NPU 测试”。启动异常记录也可直接从原侧栏的“分享启动诊断”发送，不必先打开 LoRA 页面。

## LoRA 启动修复

旧代码为 TextInputLayout 的输入框传入通用 ViewGroup.LayoutParams，第一次测量布局时发生 ClassCastException，无法转换成 LinearLayout.LayoutParams。本轮在实际 Activity 的首次绘制测试中复现了这个错误，已改为正确的布局参数，并保留旧代码的失败对照测试。

同时处理存储服务异常、未授权和页面初始化失败，增加本地启动诊断。本轮未取得用户手机的崩溃堆栈，主机复现不能代替新包的手机验证。LoRA 的 NPU 自测仍需手机执行；任意用户 LoRA 接入 WAI、普通词 embedding 加权和实时预览尚未完成。

## 预设管理

正向、负面提示词的“选择预设”现在打开管理列表。向左滑动一项后可置顶/取消置顶、编辑或删除，也可点击右侧省略号展开操作。左滑本身不删除；删除需要再次确认。

编辑支持名称、备注和提示词，负面预设还可切换默认状态。修改不新增重复条目，置顶和删除会在重启后保留。升级继续读取原来的预设文件，首次修改前保存备份；写入采用同目录原子替换并复读验证。损坏的 JSON 会报错并保留，不按空列表覆盖。

## 分辨率说明与本次修正

当前安装的 WAI UNet 输入固定为 [1,4,128,128]，VAE 输出固定为 [1,3,1024,1024]。这份预编译 context 不是可任意改变宽高的模型。其他原生尺寸需要相应 UNet/VAE contexts，或重新准备包含所需尺寸的模型包。

本版只显示当前已经安装完整模型文件的原生尺寸；缺失尺寸不再作为可用选项。Python 入口也会明确拒绝未安装尺寸，不再偷偷改成最近尺寸或将方图拉伸后当作原生输出。同名尺寸目录只下载一半时，不遮蔽已经完整安装的默认 1024 模型。

本 APK 没有新增横竖分辨率模型。因此，沿用当前模型的手机仍只有 1024×1024 原生生图；后续多尺寸模型编译是独立的待办，不应把本次界面修正算成多分辨率完成。
