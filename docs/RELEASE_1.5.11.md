# Rin NPU Agent 1.5.11

本版将已在荣耀 Magic 7 Pro / Snapdragon 8 Elite (SM8750) 上完成生图的 1.5.11 提升为正式发布。2026-09-06，项目使用者在手机测试后确认生图成功。

## 下载与安装

下载 `Rin-NPU-Agent-v1.5.11-debug-runtime-ready.apk` 并覆盖安装。已安装并跑通 1.5.11 的用户无需再次安装，本次 APK 与测试版逐字节相同。

首次使用时进入生图模式，按提示准备运行环境。模型仍由应用通过 GitHub 下载；原有 SM8750 模型四分卷和 CLIP-G 六分卷修复入口保持不变。升级用户保留应用数据及 `Download/sdxl_qnn`，无需重新下载已完整安装的模型。

当前验证设备为荣耀 Magic 7 Pro / SM8750。标准生图配置为 1024×1024、8 步；新增设备和分辨率需另行验证。

## 本版修复

UNet 编码器与解码器按真实张量名称交接，不再寻找不存在的 `output_0.raw`。输入清单会随内容更新，覆盖安装后可以替换旧缓存路径。输出清单记录精度、维度和大小，并检查缺失、截断及多路输出。

VAE 输入按 NCHW 布局准备，输出统一转换并按实际元数据读取。去噪步骤开始时立即更新进度，失败结果不会回退展示旧图片。此前的 App 进程内 QNN 执行、FP16 I/O 和 CLIP-G 定向修复均保留。
